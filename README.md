# Consolidate Drive

Eigenständige Dokumentenansicht für Anhänge aus Consolidate-Tasks.

## Start

```bash
npm install
npm run dev
```

Öffne [http://localhost:3000](http://localhost:3000) und melde dich mit:

- Consolidate-URL (z. B. `https://staging.consi.cloud`)
- E-Mail
- Passwort

## Funktionen

- Google-Drive-ähnliche Rasteransicht mit Thumbnails
- Suche, Sortierung, Gruppierung (Projekt / Verantwortlicher / Task-Typ)
- Akkordeon-Gruppen, Hover-Details, Aktionen (öffnen, Download, Teilen)
